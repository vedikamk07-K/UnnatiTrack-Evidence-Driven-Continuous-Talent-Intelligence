# Design system — industrial craft

Warm parchment `#F4EBD6` ground, panels `#FFF8F3`, wells `#F1E8D0` / `#FBF3E6`, ink `#1A0F08` with 2px borders and 4px hard offset shadows, burnt orange `#B8460F` (hover `#963709`) for primary actions, olive `#5C5640` for labels, mint `#A8F0B4` / green `#1F6B3A` for success and privacy. Square corners, no gradients, blur or soft shadows.

Type: **Oswald** bold uppercase for headings and numbers, **Space Mono** for labels, navigation badges and chart axes, **Inter** for body. Self-hosted (Fontsource) so the demo works offline.

States always pair colour with an icon and a word. Colour order *improving · stagnating · insufficient · declining · conflicting* was validated for colour-vision-deficiency separation (including the donut wrap-around): `#1F6B3A · #B07A0E · #3452D8 · #C0392B · #7B4FD6`.

Charts are drawn on grid paper with square markers; each evidence source has its own marker shape so the chart never relies on colour alone.
